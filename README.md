# hypr-scroll-indicator

A [Noctalia](https://github.com/noctalia-dev/noctalia) plugin source with one plugin:

- **[scroll-indicator](scroll-indicator/)**: dots on your bar showing which column you're on in a Hyprland
  scrolling-layout workspace.

See [scroll-indicator/README.md](scroll-indicator/README.md) for install steps.

## Maintenance
